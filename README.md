# verata-site

Marketing site for **Verata**, the trusted evidence layer for African venture. Its first product helps organizers and accelerators turn community lists into verified, searchable directories.

## Viewing the site

The whole site is a single self-contained page. Clone or download the repo and open `index.html` in any browser. There is no build step and no dependencies, although fonts load from Google Fonts.

## What's here

- `index.html`: the full marketing site (v5), responsive, single file, vanilla HTML/CSS/JS.
- `logo-assets/`: the Verata wordmark ("The Ledger"), SVG lockups, favicon monogram, and `LOGO-SPEC.md` with construction, colour, and usage rules.

## Design notes

- Warm editorial white with a single violet accent (`#46237A`); purple only marks what is verified or actionable.
- Type: Spectral (headlines), Instrument Sans (body), Geist Mono (data, labels, wordmark).
- Company names, figures, source labels, and Ask results inside product previews are illustrative and labelled on the page.
- Proof claims avoid invented live counts. Add real partner marks and outcome metrics when approved.
- The primary conversion path is an organizer partnership enquiry; the static form prepares an email to `hello@verata.co` without collecting roster data.

Status: design iteration in progress.
