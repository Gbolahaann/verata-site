# verata-site

Marketing site for **Verata**, the trusted evidence layer for African venture. Verata turns event attendee, startup, and investor lists into verified, searchable live directories.

## Viewing the site

The whole site is a single self-contained page. Clone or download the repo and open `index.html` in any browser — no build step, no dependencies (fonts load from Google Fonts).

## What's here

- `index.html` — the full marketing site (v4): responsive, single file, vanilla HTML/CSS/JS.
- `logo-assets/` — the Verata wordmark ("The Ledger"): SVG lockups, favicon monogram, and `LOGO-SPEC.md` with construction, colour, and usage rules.

## Design notes

- Warm editorial white with a single violet accent (`#46237A`); purple only marks what is verified or actionable.
- Type: Spectral (headlines), Instrument Sans (body), Geist Mono (data, labels, wordmark).
- Numbers and event names on the page are placeholder content for design review.

Status: design iteration in progress.
